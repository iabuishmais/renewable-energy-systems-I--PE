Model assumptions: Ideal, lossless switches, diodes, inductors and capacitors; a resistive DC output load (R = 120 Ω), L = 10 mH, C = 100 μF and fₛ = 20 kHz for all DC–DC modules. Output ripple is calculated from capacitor current and plotted with an expanded vertical scale. The inverting buck–boost output is shown with negative polarity. These steady-state CCM waveforms omit switching transients, parasitic effects, start-up and device ratings. Inverter voltage is shown before any AC filter; its THD includes switching-frequency components. Values are intended for education, not hardware sizing.
